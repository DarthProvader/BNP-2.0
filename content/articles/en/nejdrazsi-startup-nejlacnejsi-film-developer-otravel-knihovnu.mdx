## Anthropic Closes In on a Trillion

**Anthropic** raised **$65 billion** in a Series H round Thursday, pushing its post-money valuation to **$965 billion** — near enough to a trillion to matter, and almost certainly its last major private raise before a highly anticipated IPO. TechCrunch notes this is an unprecedented valuation for a private AI company, and it sets up what would be the first major AI lab to go public.

On the same day, Anthropic launched **Claude Opus 4.8** with a new **Dynamic Workflows** tool for coordinating swarms of subagents working in parallel on distributed tasks. The Verge leads with the model's improved "honesty" — trained to acknowledge uncertainty rather than confidently filling gaps. The community's first response came from developer **Theo**, who posted `slotslop` on Twitter: a terminal tool built with Opus 4.8 that randomizes agent/model/effort selection like a slot machine. Paradoxically, building it *reduced* his daily API spend.

A subplot worth watching: **Elon Musk** is publicly framing Anthropic's compute lease with **SpaceX** as short-term and easily cancelled — while SpaceX's own S-1 filing describes payments running through **May 2029**. As TechCrunch put it: opinions vary.

## The Internet Is Being Rewired for Machines

**AWS**, **Cloudflare**, and other cloud infrastructure providers are actively redesigning the internet not for human browsers but for AI agents, TechCrunch reports. Agents generate different traffic patterns — distinct auth requirements, different caching strategies, different latency tolerances — and the web built for people increasingly can't serve machines at scale. The architects know it, and they're moving.

In parallel, large commodity exchanges are developing **AI token futures**: derivatives that would treat AI compute output as a tradeable raw material like bandwidth or electricity. If adopted, betting on the cost of a Claude output would work like betting on an oil barrel. *The moment AI tokens become a commodity, "AI access" stops being a product category and starts being macroeconomic infrastructure.*

The **Latent Space** podcast's episode with **Cognition** (makers of Devin) illustrated the paradox cleanly: even as companies like Shopify, Stripe, and Ramp build in-house coding agents, Cognition was oversubscribed on a fresh **$1 billion Series D**. Their argument: DIY agent frameworks don't undercut specialists — they validate that the problem is real enough to be worth solving twice.

## A Lawsuit, a $2,000 Film, and a Note About Math

**CNN** filed a lawsuit against **Perplexity** in a New York court, alleging the AI answer engine reproduces verbatim articles — including paywalled content — and delivers them for free. Perplexity hasn't yet responded. The underlying legal question is genuinely subtle: if AI "answers" by directly quoting a news article, is that research, or repackaging with the revenue layer stripped out? The outcome will set precedent for how every media outlet relates to AI aggregators going forward.

At **Tribeca Film Festival** next month: **Dreams of Violets**, a 75-minute AI-generated dramatization of the Iranian government's mass killing of protesters in January 2026. Fully AI characters and imagery throughout. Total production budget: **$2,000**. The Verge reported it. A comparable human production would run into the tens of millions. *Nobody leads with that part.*

**Demis Hassabis** this week retweeted a mathematician's note about a new human-discovered result in additive combinatorics — a problem that fell to humans, but using methods related to the AI proof of the unit distance conjecture. His comment: *"After AlphaGo, human Go players noticeably improved. I expect a similar pattern in math."* A quiet observation about a loop most people miss: AI lifting human capability rather than simply replacing it.

## One Angry Java Developer

The most provocative story of the day came from Ars Technica. A developer, fed up with "vibe coders" — programmers who write vague prompts, accept whatever the agent generates, and ship without review — secretly embedded a **prompt injection** inside the popular Java testing library **jqwik**. The instruction: if an AI coding agent accesses this project, delete the application's output.

The attack works because AI coding agents implicitly trust repository content. READMEs, code comments, documentation — all of it becomes agent context, and context is instruction. *A hostile instruction can sit silently inside an open-source package for months until the right agent with the right permissions comes along.*

What separates this from the GitHub supply chain attacks covered earlier in May is motive. Those were criminal — profit, espionage, sabotage. This is professional contempt: a skilled developer punishing those who casualize the craft. That changes the threat model entirely. You can't price an attacker out of disgust, and standard security heuristics aren't looking for politically motivated injections in test libraries. Who audits open-source packages for hidden prompt injections? How do you distinguish a malicious instruction from "clever documentation"? How long can agents keep treating repository content as authoritative truth? These are now real, open questions.
